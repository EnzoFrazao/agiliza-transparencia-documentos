# Funcionalidades — Agiliza Transparência

Esta pasta traduz o backlog ativo em leitura de produto. A fonte de planejamento é
[`../../planejamento/backlog-completo.xlsx`](../../planejamento/backlog-completo.xlsx): a aba
**Lista completa** define o universo do MVP completo e as abas **Sprint 9** a **Sprint 14** definem
o recorte executável da V1 mínima.

| Documento | Uso |
| --- | --- |
| [MVP completo](mvp-completo.md) | Catálogo integral da aba geral, sem excluir itens não escalonados. |
| [V1 mínima](v1-minima.md) | Entregas granulares previstas para as Sprints 9–14. |
| [Rastreabilidade](rastreabilidade-backlog.md) | Matriz granular: atividade geral, sprint, nó de fluxo e regra. |

## Convenções

- **V1 mínima:** item com atividade granular nas Sprints 9–14.
- **Status técnico / Integração-evidência:** leitura operacional no backlog ativo; separa a
  implementação comprovada da integração em `main` ou da ausência de início. Não altera o
  planejamento original da Sprint.
- **Planejado:** item já associado a uma ou mais Sprints na aba geral.
- **A definir:** item listado no MVP completo sem Sprint definida.
- **Parecer Guilherme:** evidência usada para formar a V1; `não` ou ausência de marcação não
  eliminam o item do MVP completo.

As regras normativas e os critérios de aceite permanecem em
[`../regras-de-negocio.md`](../regras-de-negocio.md). Esta pasta não cria contratos além do backlog.
