# Requisitos preservados no acervo

As versões recebidas e substituídas são preservadas em `historico/`. Desde 2026-09-10, a autoridade
dos requisitos funcionais transversais vigentes está em
`../../agiliza-transparencia-coordenacao/docs/requisitos/v1`.

O acervo não edita o contrato vigente: guarda evidências e versões históricas, com hashes no
`MANIFESTO_SHA256.csv`.
