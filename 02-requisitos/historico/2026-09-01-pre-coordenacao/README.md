# Levantamento de requisitos — Agiliza Transparência

Esta é a fonte canônica dos documentos institucionais operacionais do MVP.

## Documentos vigentes

- `decisoes/2026-08-31-reuniao-apresentacao-agiliza.md`: decisão institucional mais recente e
  primeira autoridade nos pontos que corrige.
- `levantamento_de_requisitos_final.md` v6.0: contrato funcional consolidado.
- `lista_de_funcionalidades_tecnicas.md` v6.0 e `lista_de_funcionalidades_gestoras.md` v11.0:
  capacidades da plataforma e responsabilidades humanas.
- `pontos_em_aberto.md`: decisões ainda não autorizadas.

- `fluxogramas.md`: versão 7.0 dos fluxos Mermaid vigentes — ciclo e coleta.

- `Tesauro_MA_Transparente_v2_3_17_03.xlsx`: versão anterior preservada para conferência e proveniência.

A cópia em `agiliza-transparencia-front/docs` é um espelho e pode ficar temporariamente defasada
durante uma consolidação. Para atualizá-la ou conferir divergências, execute na pasta
`agiliza-transparencia-front/frontend`:

```powershell
npm run docs:sync
npm run docs:check
```
