# Levantamento de requisitos — Agiliza Transparência

Esta é a fonte canônica dos documentos institucionais operacionais do MVP.

## Documentos vigentes

- `contextoSTC.md`: contexto v9.0 preservado, com o §33 como correção vigente posterior ao §32.
- `levantamento_de_requisitos_final.md`, `lista_de_funcionalidades_tecnicas.md`, `lista_de_funcionalidades_gestoras.md` e `pontos_em_aberto.md`: requisitos e pendências operacionais.
- `fluxogramas.md`: versão 6.1 dos dois fluxos Mermaid vigentes — ciclo e coleta.
- `Tesauro_MA_Transparente_v2_6_agosto_2026.xlsx`: fonte mais recente recebida; o nome v2.6 diverge da versão interna v2.5, registrada em P-024.
- `Tesauro_MA_Transparente_v2_3_17_03.xlsx`: versão anterior preservada para conferência e proveniência.

A cópia corrente em `agiliza-transparencia-front/docs` é um espelho. Para atualizá-la ou conferir divergências, execute na pasta `agiliza-transparencia-front/frontend`:

```powershell
npm run docs:sync
npm run docs:check
```
